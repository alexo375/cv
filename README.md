# 📄 Резюме и Сопроводительное Письмо

Репозиторий с исходным кодом моего резюме и сопроводительного письма, сверстанных на LaTeX.

---

## 🛠️ Стек

- 📝 **LaTeX**
- 🔧 **Latexmk** для автоматизации многопроходной компиляции и разрешения ссылок
- 🛠️ **GNU Make** для удобного управления сборкой
- 🐳 **Docker / VS Code Devcontainers** для виртуализации сборочного окружения

---

## ⚙️ Makefile команды

В корне проекта подготовлен `Makefile`. Основные команды сборки:

* Собрать все документы (CV и письмо):
  ```bash
  make
  ```
  Или явно:
  ```bash
  make cv letter
  ```
* Выбрать движок для сборки (по умолчанию `pdflatex`):
  ```bash
  ENGINE=xelatex make
  # или
  ENGINE=lualatex make
  ```
* Очистить временные файлы сборки (PDF останутся):
  ```bash
  make clean
  ```
* Полная очистка проекта (удаление папки `build` и PDF в корне):
  ```bash
  make cleandist
  ```
